# 鲸鱼娘变化器

把网络梗「滑动变阻器」做成物理实验器材的网页小玩具，内置三套展示主题：

- **主题一 · 经典滑轨**（默认）：经典 5 档三视图立绘（小鲸鱼 → 鲸祖），拖动滑片在 5 档之间平滑变化，展示区 6:5 完整显示、不裁切。
- **主题二 · 鲸鱼娘 v2 六档**：同一张源图挤压出的 B–G 六档，3:4 竖版展示，拖动滑片逐档变化。
- **主题三 · 暴击展示**：收起滑轨，改成「点一次推进一帧」的逐帧装置。点一下立绘或「暴击展示」按钮，画面前进一帧；不点就停在当前帧，不做任何自动播放。动作可选撞玻璃（默认）/ 走路 / 挥手 / 蹦跳 / 坐下 / 摔倒 / 连招，两行选择器：第一行挑动作，第二行挑版本（精细版 8 帧 / 简版 16 帧 / 九宫格 9 帧）。连击到 30 判定脱力，自动放完同版本的摔倒序列后停在末帧，再点一下重新站起。

纯静态、零依赖、零构建，双击 `index.html` 就能玩。

> v2 六档不是 AI 重绘，而是对同一张源图的确定性挤压变形，所以极端档位（尤其 B）会有轻微拉伸与衣服褶皱变形，这是「挤压图」的预期风格。

## 玩法

- **主题切换**：右下角「设置 → 主题」可在三套展示之间切换，选择存在 localStorage
- **拖动滑片**（主题一 / 主题二）：鼠标、触屏都可以
- **键盘**：方向键 ±2%，`Shift` + 方向键 ±10%，`PageUp/PageDown` ±10%，`Home/End` 到两端
- **滚轮**：在滑轨上滚动微调（主题一 / 主题二）
- **音效**：滑动时有实时合成的摩擦声，跨档时有咔哒声（首次交互后才会启用，这是浏览器的限制）
- **设置**：右下角「设置」可改主题、标题、副标题、当前主题的档位名称与文案、主题色；配置存在浏览器 localStorage

## 主题三：帧素材

三套素材是**同一组动作的三个版本**，不是三组不同动作，所以做成「动作 × 版本」两级：

```
动作：撞玻璃 | 走路 | 挥手 | 蹦跳 | 坐下 | 摔倒 | 连招
版本：只列当前动作真实存在的版本（撞玻璃→姿态帧/九宫格，其它→精细版/简版）
```

| family | 素材来源 | 动作 | 帧数 | 尺寸 | 图集 |
| --- | --- | --- | --- | --- | --- |
| `v443` 精细版 | `蓝发鲸鱼女仆_全部图片与GIF_分类合集/03_五组动作/*/[组]_动画.gif` | 走 / 挥 / 蹦 / 坐 / 摔 | 8 | 443×443 透明 | 4×2 |
| `v315` 简版 | `蓝发鲸鱼女仆_全部素材分类合集/02_可播放GIF动画/*/*.gif` | 走 / 挥 / 蹦 / 坐 / 摔 | 16 | 315×311 纯色底 | 4×4 |
| `impact` 九宫格 | `蓝发鲸鱼女仆 · 图片与 GIF 完整合集/02_初版角色_反弹摔倒/GIF动画/蓝发鲸娘女仆撞玻璃反弹记.gif` | 撞玻璃 | 9 | 138×138 透明 | 3×3 |
| `impact` 姿态帧 | 贴玻璃立绘 `assets/impact/new-burst/still.png` + 10 组 transform 参数 | 撞玻璃 | 10（程序化） | — | — |

- **v315 需要抠底**：GIF 的淡蓝 / 淡粉纯色底不透明，脚本逐帧从四角泛滥填充去背景（thresh 26），再清掉 alpha < 40 的边缘噪点。
- **九宫格不是动作**：它是同一张立绘的 3×3 切块，按序播放只是镜头从头顶扫到胸腰，像镜头推移而不像动作。保留它是因为「贴脸 + 脸红 + 冲击裂纹」的构图最贴撞玻璃语境，作为姿态帧之外的一个版本。
- **两套画风角色身高差约 4%**：展示层按高度铺满，不做缩放补偿——任何 >1 的缩放都会把头发或脚裁掉。

> **为什么撞玻璃那 10 组 GIF 不能当动作**：实测第 1–9 帧是**同一张立绘按 3×3 切块**（头顶 / 脸 / 胸腰），不是角色动作序列——把 `拆分单帧/` 的 9 个 PNG 按行优先拼回去与原图的平均像素差只有 8.98（全白基线 70.7）。GIF 帧延时又烧在文件里，JS 无法调速、无法 seek。所以撞玻璃改用姿态帧 + 九宫格；分类合集里的五组动作才是真序列。

素材由 `tools/sync_actions.py` 统一生成：一次性输出 11 张图集（约 2.5MB）和 `assets/burst/sets.js`。`app.js` 不硬编码帧数、网格与尺寸，只消费 `window.BURST_SETS`；改素材后重跑脚本即可，前端不用动。

```bash
python3 tools/sync_actions.py
```

### 重新同步撞击素材

素材目录默认是 `/Users/yaobinsun/Downloads/jyl-pet/蓝发鲸鱼女仆 · 图片与 GIF 完整合集`，改路径后重跑即可（原图直拷、不重采样）：

```bash
cd whale-girl-changer
python3 tools/sync_impact.py
```

脚本会按 `tools/sync_impact.py` 里的 `SERIES` 表，把每组 `still.png` 与 `anim.gif` 写进 `assets/impact/<id>/`，与 `app.js` 的 `IMPACT_SERIES` 一一对应。

## 重新生成六档图（主题二）

源图在 `assets/source/g-jiya.jpeg`。挤压脚本在 `tools/squeeze_cups.py`，用项目内 Python 环境运行：

```bash
cd whale-girl-changer
../whale-girl-changer/.venv-img/bin/python tools/squeeze_cups.py
```

脚本会在 `assets/` 下重写 `b.jpeg … g.jpeg`（宽 1280、JPEG q88），并把预览图输出到 `tools/preview/`（六档竖排 + B/G 对照）。

可调参数在脚本顶部：

- `CX / R / Y0, Y1`：胸部窗口（横向中心、半宽、纵向范围，按 1792×2400 源图坐标）
- `CUPS`：六档挤压强度 `a_h`，越大压得越小；G 固定为 0（原图）
- `OUT_WIDTH`：输出宽度

脚本内置横向映射单调性断言，参数过大导致采样折叠时会直接报错。

## 安装到 iPhone / Mac（PWA）

是 PWA，安装后独立窗口、离线可用。前提是部署到 HTTPS 地址（GitHub Pages / Cloudflare Pages / Vercel / Netlify 均可），然后：

- **iPhone / iPad（Safari）**：分享 → 添加到主屏幕
- **Mac（Safari）**：文件 → 添加到 Dock
- **Mac（Chrome）**：地址栏安装图标 → 安装

改了资源后，把 `sw.js` 里的 `CACHE_NAME` 改一下（如 `whale-changer-v11`），浏览器会自动清掉旧缓存。

## 实现要点

- **连续变化**：当前素材集的帧叠放，按滑片位置计算三角权重做 opacity 交叉淡入淡出，不是简单跳帧
- **平滑跟手**：目标值 + 每帧插值，点击轨道也会平滑滑过去
- **主题与素材集**：`FRAME_SETS` 里两套滑轨素材自带帧顺序与档位文案；切主题时按 `theme` 选素材集重建帧与刻度，两套文案分别保存在 `gradesBySet`
- **逐帧推进**：`burst.count` 既是连击数也是帧号，点一次 +1，`count % 帧数` 决定当前帧；没有任何定时器推动画面，不点就停在当前帧。姿态帧改 `--f-*` CSS 变量，动作帧只改 `background-position`（图集换帧零解码开销）。连击到 30 触发 `startExhaust()` 自动放完同版本摔倒序列并停在末帧，再点一次 `reviveBurst()` 回到第 1 帧
- **数据驱动**：帧数 / 网格 / 宽高比全部来自 `assets/burst/sets.js`（`tools/sync_actions.py` 生成），`paintSheetFrame()` 按 `set.cols`、`set.rows` 算 `background-position`，所以 4×2、4×4、3×3 共用同一段代码；新增一组素材只需改脚本里的 `SOURCES` 再重跑
- **切动作留在同版本**：`preferredBurstSet(action, family)` 优先选同一 family，避免从「简版走路」跳到「精细版挥手」时画风突变；连招也只在同 family 内串联
- **脱力不放穿**：`burst.exhaustPlaying` 在摔倒序列播放期间为真，此时点击直接忽略——否则连点会一路点穿，动画刚起第一帧就被「复活」取消，等于看不到脱力
- **音效**：Web Audio API 实时合成——摩擦声（带通白噪声）、咔哒声（三角波），不加载任何音频文件
- **无后端**：所有配置存 localStorage，旧版 `theme: cup` 与 `grades` 配置会自动迁移
- **同源同画布**：同一素材集内的帧尺寸与构图一致，切换不跳位
