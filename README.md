# 鲸鱼娘变化器

把网络梗「滑动变阻器」做成物理实验器材的网页小玩具，内置四套展示主题：

- **主题一 · 经典滑轨**（默认）：经典 5 档三视图立绘（小鲸鱼 → 鲸祖），拖动滑片在 5 档之间平滑变化，展示区 6:5 完整显示、不裁切。
- **主题二 · 鲸鱼娘 v2 六档**：同一张源图挤压出的 B–G 六档，3:4 竖版展示，拖动滑片逐档变化。
- **主题三 · 五档身材 A–E**：沿用主题一的滑轨逻辑（5 档交叉淡入淡出、6:5 完整显示、初始 50%），素材换成 `Gemini_A..E` 五张身材立绘，一档一档滑过去看身形变化。
- **主题四 · 暴击展示**：收起滑轨，改成「点一次推进一帧」的逐帧装置。点「神临」或直接点立绘，画面前进一帧；不点就停在当前帧。第二行 5 个按钮切换 5 种身材（A–E），每种身材各带一整套动作素材；第二行下方的「破壁」是 A–E 共用的**突破次元**动画（9 帧，点一次自动放到末帧）。动作 6 个：走路 / 挥手 / 蹦跳 / 摔倒 / 坐下 / 连招；在「神临」上**按住 2 秒**进入自动播放：按钮转红底玻璃色、主标签变「取消」，循环播当前动作；循环期间可以随意切换动作与身材，每个组合各自记进度，点一下「取消」结束循环并停在当前帧。档位与连击数（砰 / 砰砰 / 鲸涛 / 脱力）显示在「神临」按钮副标题上，不再浮在人物身上。连击到 30 判定脱力，自动放完当前身材的摔倒序列后停在末帧，再点一下回到神临立绘。

纯静态、零依赖、零构建，双击 `index.html` 就能玩。

> v2 六档不是 AI 重绘，而是对同一张源图的确定性挤压变形，所以极端档位（尤其 B）会有轻微拉伸与衣服褶皱变形，这是「挤压图」的预期风格。

## 玩法

- **主题切换**：右下角「设置 → 主题」可在四套展示之间切换，选择存在 localStorage
- **拖动滑片**（主题一 / 二 / 三）：鼠标、触屏都可以
- **键盘**：方向键 ±2%，`Shift` + 方向键 ±10%，`PageUp/PageDown` ±10%，`Home/End` 到两端
- **滚轮**：在滑轨上滚动微调（主题一 / 二 / 三）
- **音效**：滑动时有实时合成的摩擦声，跨档时有咔哒声（首次交互后才会启用，这是浏览器的限制）
- **设置**：右下角「设置」可改主题、标题、副标题、当前主题的档位名称与文案、主题色；配置存在浏览器 localStorage

## 主题四：帧素材

按钮分三层：第一行动作、第二行身材、「神临」下面是「破壁」。全部素材由 `tools/sync_actions.py` 生成，`app.js` 只消费 `assets/burst/sets.js`：

```
动作（第一行）  走路 | 挥手 | 蹦跳 | 摔倒 | 坐下 | 连招
身材（第二行）  A | B | C | D | E          ← 每种身材各带一整套动作素材
神临 / 破壁    神临 = 当前身材的静止立绘；破壁 = 三支共用的突破次元动画（难度 1/2/3）
```

| 素材 | 来源 | 帧数 | 尺寸 | 产出 |
| --- | --- | --- | --- | --- |
| 神临立绘 ×5 | `jyl-pet/Gemini_A..E.jpeg/png` | — | 1536×2706 / 944×1665 白底 | `body-a..e.webp`（720 宽、四角泛滥抠底） |
| 动作 ×25 | `jyl-pet/dafeiyu/人物[A-E]/<动作>_16帧连贯动作图.png` | 16/组 | 4×4 拼图，每格约 315×311 | `<身材>-<动作>.webp`（4×4 图集） |
| 连招 ×5 | 上面五组按按钮顺序串联 | 80 | — | 复用五张图集，不额外存图 |
| 破壁 ×3 | `蓝发鲸鱼女仆 ·破壁/` 下三支 9 帧动画 | 9 | 427×401 / 414×414 / 414×413 | `break-1..3.webp`（3×3 图集） |

- **图集不拆帧**：动作素材自带 4×4 连贯动作图，实测与同目录 GIF 的 16 帧逐帧差异为 0，直接当 sprite 图集用，换帧只改 `background-position`。
- **神临立绘用 `contain`**：立绘是 0.567 的窄长图，`cover` 在 3:4 的展示区里会切掉约 16% 的上下边缘（头发和脚）；卡片层高度取 96%，不裁头脚。
- **换身材只换素材**：动作、帧号、连击数都保留，只是把图集/立绘换成这一位的；连招也是各身材自己的 80 帧。
- **破壁三支代表三种难度**：难度 1 后仰反弹 / 难度 2 反弹摔倒 / 难度 3 撞击挤压。点一次等概率随机挑一支（不连出同一支），副标题报本次难度。
- **帧号由点击次数决定**（`count % total`），没有时间驱动的定时器；只有长按自动连播、破壁播放与脱力自动播放例外。
- **自动连播不脱力**：`count` 管帧号，`hits` 只管手动连击，长按自动连播只推进 `count`，所以播多久都不会脱力；只有单次点击累计到 30 才触发脱力摔倒。

素材路径与清单集中在 `tools/sync_actions.py` 顶部（`BODIES` / `ACTIONS` / `COMBO_ORDER` / `BREAKS`），改完重跑即可，前端不用动：

```bash
python3 tools/sync_actions.py
```

```bash

```

## 重新生成六档图（主题二）

源图在 `assets/source/g-jiya.jpeg`。挤压脚本在 `tools/squeeze_cups.py`，用项目内 Python 环境运行：

```bash
cd whale-girl-changer
../whale-girl-changer/.venv-img/bin/python tools/squeeze_cups.py
```

脚本会在 `assets/` 下重写 `b.jpeg … g.jpeg`（宽 1280、JPEG q88），并把预览图输出到 `tools/preview/`（六档竖排 + B/G 对照）。

可调参数在脚本顶部：

- `CX / R / Y0, Y1`：胸部窗口（横向中心、半宽、纵向范围，按 1792×2400 源图坐标）
- `CUPS`：六档挤压强度 `a_h`，越大压得越小；G 固定为 0（原图）
- `OUT_WIDTH`：输出宽度

脚本内置横向映射单调性断言，参数过大导致采样折叠时会直接报错。

## 安装到 iPhone / Mac（PWA）

是 PWA，安装后独立窗口、离线可用。前提是部署到 HTTPS 地址（GitHub Pages / Cloudflare Pages / Vercel / Netlify 均可），然后：

- **iPhone / iPad（Safari）**：分享 → 添加到主屏幕
- **Mac（Safari）**：文件 → 添加到 Dock
- **Mac（Chrome）**：地址栏安装图标 → 安装

改了资源后，把 `sw.js` 里的 `CACHE_NAME` 改一下（如 `whale-changer-v14`），浏览器会自动清掉旧缓存。

## 实现要点

- **连续变化**：当前素材集的帧叠放，按滑片位置计算三角权重做 opacity 交叉淡入淡出，不是简单跳帧
- **平滑跟手**：目标值 + 每帧插值，点击轨道也会平滑滑过去
- **主题与素材集**：`FRAME_SETS` 里三套滑轨素材自带帧顺序与档位文案；切主题时按 `theme` 选素材集重建帧与刻度，三套文案分别保存在 `gradesBySet`
- **逐帧推进**：`burst.count` 是帧号（推进次数），点一次 +1，`count % 帧数` 决定当前帧；`burst.hits` 单独记手动连击数。`burst.view` 有三种：`shenlin`（静止立绘）/ `sheet`（动作图集）/ `break`（破壁）。时间驱动只有三处：长按自动连播、破壁播放、脱力摔倒播放。动作帧只改 `background-position`（图集换帧零解码开销），神临立绘单独一层，换身材只换 `src`
- **长按 2 秒 = 自动播放**：`pointerdown` 起 2 秒计时并显示蓄力进度条，到点把按钮转成红底玻璃、主标签变「取消」，每 110ms 推进一帧；松手不停，点一下按钮（或点立绘）才结束循环并停在当前帧。循环只推进画面，不累计连击、不脱力。播放中切换动作/身材不会中断循环，每个「身材:动作」在 `autoPos` 里各记一份进度，切回来接着播；长按松手后浏览器补发的 click 用 `suppressClick` 吃掉，避免刚开的循环被自己取消
- **破壁随机**：三支图集 130ms/帧放完停末帧，副标题报 `破壁 · 难度 N`；`pickBurstBreak()` 等概率抽签但排除上一支，`breakToken` 负责作废还没加载/没播完的旧播放，`loadBurstSheet()` 首次点击先等解码
- **数据驱动**：帧数 / 网格 / 宽高比全部来自 `assets/burst/sets.js`（`tools/sync_actions.py` 生成），`paintSheetFrame()` 按 `set.cols`、`set.rows` 算 `background-position`，换网格不用改 JS；新增素材只需改脚本顶部的 `BODIES` / `ACTIONS` / `BREAKS` 再重跑
- **档位显示在按钮上**：档位与连击数（砰 / 砰砰 / 鲸涛 / 脱力）写进「神临」按钮的副标题（`setBurstReadout()`），不再浮在人物身上挡脸；自动连播时改报「自动连播 · ×N」
- **脱力只看手动连击**：手动连击到 30 触发 `startExhaust()`，自动放完当前身材的摔倒序列并停在末帧，再点一次 `reviveBurst()` 回到神临立绘。`burst.exhaustPlaying` 在播放期间为真，此时点击直接忽略，避免连点把脱力点穿
- **音效**：Web Audio API 实时合成——摩擦声（带通白噪声）、咔哒声（三角波），不加载任何音频文件
- **无后端**：所有配置存 localStorage，旧版 `theme: cup` 与 `grades` 配置会自动迁移
- **同源同画布**：同一素材集内的帧尺寸与构图一致，切换不跳位
