# 鲸鱼娘变化器

把网络梗「滑动变阻器」做成物理实验器材的网页小玩具，内置三套展示主题：

- **主题一 · 经典滑轨**（默认）：经典 5 档三视图立绘（小鲸鱼 → 鲸祖），拖动滑片在 5 档之间平滑变化，展示区 6:5 完整显示、不裁切。
- **主题二 · 鲸鱼娘 v2 六档**：同一张源图挤压出的 B–G 六档，3:4 竖版展示，拖动滑片逐档变化。
- **主题三 · 暴击展示**：收起滑轨，改成「点一次推进一帧」的逐帧装置。单击按钮或点立绘，画面前进一帧；不点就停在当前帧。按钮组上半是「单击」，下半是「长按」（按住 180ms 后每 110ms 自动循环，松手停住）。动作固定 7 个：撞墙（默认）/ 走路 / 挥手 / 蹦跳 / 摔倒 / 坐下 / 连招；撞墙的姿态帧底图可从三套人物卡（微澜 / 丰满 / 汹涌）里换。档位与连击数（砰 / 砰砰 / 鲸涛 / 脱力）显示在「单击」按钮副标题上，不再浮在人物身上。连击到 30 判定脱力，自动放完摔倒序列后停在末帧，再点一下重新站起。

纯静态、零依赖、零构建，双击 `index.html` 就能玩。

> v2 六档不是 AI 重绘，而是对同一张源图的确定性挤压变形，所以极端档位（尤其 B）会有轻微拉伸与衣服褶皱变形，这是「挤压图」的预期风格。

## 玩法

- **主题切换**：右下角「设置 → 主题」可在三套展示之间切换，选择存在 localStorage
- **拖动滑片**（主题一 / 主题二）：鼠标、触屏都可以
- **键盘**：方向键 ±2%，`Shift` + 方向键 ±10%，`PageUp/PageDown` ±10%，`Home/End` 到两端
- **滚轮**：在滑轨上滚动微调（主题一 / 主题二）
- **音效**：滑动时有实时合成的摩擦声，跨档时有咔哒声（首次交互后才会启用，这是浏览器的限制）
- **设置**：右下角「设置」可改主题、标题、副标题、当前主题的档位名称与文案、主题色；配置存在浏览器 localStorage

## 三套主题

| 主题 | 档位 | 素材 | 展示区 |
| --- | --- | --- | --- |
| 主题一 · 经典滑轨（默认） | Lv.1–Lv.5：小鲸鱼 / 鲸鱼娘 / 鲸灵 / 鲸圣 / 鲸祖 | `assets/aligned/a,c,d,g,h.jpeg` | 6:5，完整显示 |
| 主题二 · v2 六档 | Lv.1–Lv.6：B 微澜 … G 鲸祖 | `assets/b,c,d,e,f,g.jpeg` | 3:4，铺满裁切 |

## 主题三：帧素材

主题三有两条素材线，都由 `tools/sync_actions.py` 生成，`app.js` 只消费 `assets/burst/sets.js`：

```
动作（第一行）  撞墙 | 走路 | 挥手 | 蹦跳 | 摔倒 | 坐下 | 连招
人物卡（第二行）微澜 | 丰满 | 汹涌        ← 只替换「撞墙」姿态帧的底图
```

| 素材 | 来源 | 帧数 | 尺寸 | 产出 |
| --- | --- | --- | --- | --- |
| 五组动作 | `蓝发鲸鱼女仆_全部图片与GIF_分类合集/03_五组动作/*/[组]_动画.gif` | 8 | 443×443 透明 | `walk/wave/jump/fall/sit.webp`（4×2 图集） |
| 撞墙姿态帧 | 人物卡 + 10 组 transform 参数 | 10（程序化） | — | 无图集，只改 CSS 变量 |
| 连招 | 上面五组按按钮顺序串联 | 40 | — | 复用五张图集 |
| 人物卡 | `01_人物原图与造型修改/*.png` | 3 | 944×1665 白底 | `card-1..3.webp`（720 宽、抠底透明） |

- **人物卡用 `contain` 而不是 `cover`**：卡片是 0.567 的窄长图，`cover` 在 3:4 的展示区里会切掉约 16% 的上下边缘（头发和脚）。卡片层高度只占 92%，撞墙最大推到 1.116 时也刚好不裁切。
- **人物卡只影响撞墙**：动作图集是固定美术，换卡不会改变走路/挥手等动作。
- **连招不跨画风**：现在只有一套动作素材，连招就是五组动作按「走路 → 挥手 → 蹦跳 → 摔倒 → 坐下」串成 40 帧。
- **帧号由点击次数决定**（`count % total`），没有时间驱动的定时器；只有长按自动循环与脱力自动播放例外。

> **为什么撞墙那 10 组 GIF 不能当动作**：实测第 1–9 帧是**同一张立绘按 3×3 切块**（头顶 / 脸 / 胸腰），不是角色动作序列——把 `拆分单帧/` 的 9 个 PNG 按行优先拼回去与原图的平均像素差只有 8.98（全白基线 70.7）。所以撞墙改用姿态帧（人物卡 + transform），分类合集里的五组动作才是真序列。

素材路径与人物卡清单集中在 `tools/sync_actions.py` 顶部（`ACTIONS` / `CARDS` / `COMBO_ORDER`），改完重跑即可，前端不用动：

```bash
python3 tools/sync_actions.py
```

## 重新生成六档图（主题二）

源图在 `assets/source/g-jiya.jpeg`。挤压脚本在 `tools/squeeze_cups.py`，用项目内 Python 环境运行：

```bash
cd whale-girl-changer
../whale-girl-changer/.venv-img/bin/python tools/squeeze_cups.py
```

脚本会在 `assets/` 下重写 `b.jpeg … g.jpeg`（宽 1280、JPEG q88），并把预览图输出到 `tools/preview/`（六档竖排 + B/G 对照）。

可调参数在脚本顶部：

- `CX / R / Y0, Y1`：胸部窗口（横向中心、半宽、纵向范围，按 1792×2400 源图坐标）
- `CUPS`：六档挤压强度 `a_h`，越大压得越小；G 固定为 0（原图）
- `OUT_WIDTH`：输出宽度

脚本内置横向映射单调性断言，参数过大导致采样折叠时会直接报错。

## 安装到 iPhone / Mac（PWA）

是 PWA，安装后独立窗口、离线可用。前提是部署到 HTTPS 地址（GitHub Pages / Cloudflare Pages / Vercel / Netlify 均可），然后：

- **iPhone / iPad（Safari）**：分享 → 添加到主屏幕
- **Mac（Safari）**：文件 → 添加到 Dock
- **Mac（Chrome）**：地址栏安装图标 → 安装

改了资源后，把 `sw.js` 里的 `CACHE_NAME` 改一下（如 `whale-changer-v14`），浏览器会自动清掉旧缓存。

## 实现要点

- **连续变化**：当前素材集的帧叠放，按滑片位置计算三角权重做 opacity 交叉淡入淡出，不是简单跳帧
- **平滑跟手**：目标值 + 每帧插值，点击轨道也会平滑滑过去
- **主题与素材集**：`FRAME_SETS` 里两套滑轨素材自带帧顺序与档位文案；切主题时按 `theme` 选素材集重建帧与刻度，两套文案分别保存在 `gradesBySet`
- **逐帧推进**：`burst.count` 既是连击数也是帧号，点一次 +1，`count % 帧数` 决定当前帧。唯一的时间驱动是长按（`pointerdown` 180ms 后每 110ms 循环，`pointerup/cancel/lostpointercapture` 停止）与脱力自动播放。撞墙姿态帧改人物卡层的 `--f-*` CSS 变量，动作帧只改 `background-position`（图集换帧零解码开销）。连击到 30 触发 `startExhaust()` 自动放完摔倒序列并停在末帧，再点一次 `reviveBurst()` 回到第 1 帧
- **数据驱动**：帧数 / 网格 / 宽高比全部来自 `assets/burst/sets.js`（`tools/sync_actions.py` 生成），`paintSheetFrame()` 按 `set.cols`、`set.rows` 算 `background-position`，换网格不用改 JS；新增一组素材只需改脚本里的 `ACTIONS` 再重跑
- **档位显示在按钮上**：原来浮在人物顶部的「砰砰 +1 ×N」会挡脸，现在写进「单击」按钮的副标题（`setBurstReadout()`），脱力时转金色
- **脱力不放穿**：`burst.exhaustPlaying` 在摔倒序列播放期间为真，此时点击直接忽略——否则连点会一路点穿，动画刚起第一帧就被「复活」取消，等于看不到脱力
- **音效**：Web Audio API 实时合成——摩擦声（带通白噪声）、咔哒声（三角波），不加载任何音频文件
- **无后端**：所有配置存 localStorage，旧版 `theme: cup` 与 `grades` 配置会自动迁移
- **同源同画布**：同一素材集内的帧尺寸与构图一致，切换不跳位
