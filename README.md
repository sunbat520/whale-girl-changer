# 鲸鱼娘变化器

把网络梗「滑动变阻器」做成物理实验器材的网页小玩具，内置三套展示主题：

- **主题一 · 经典滑轨**（默认）：经典 5 档三视图立绘（小鲸鱼 → 鲸祖），拖动滑片在 5 档之间平滑变化，展示区 6:5 完整显示、不裁切。
- **主题二 · 鲸鱼娘 v2 六档**：同一张源图挤压出的 B–G 六档，3:4 竖版展示，拖动滑片逐档变化。
- **主题三 · 暴击展示**：收起滑轨，固定展示贴玻璃立绘；点击立绘或「暴击展示」按钮就是一次撞击——镜头冲击、震屏、白闪裂纹、碎玻璃粒子、连击跳字同时触发。连点会累加连击（砰 → 砰砰 → 鲸涛 → 鲸祖降临），点得越急冲击越快越猛，900ms 不点则连击归零。

纯静态、零依赖、零构建，双击 `index.html` 就能玩。

> v2 六档不是 AI 重绘，而是对同一张源图的确定性挤压变形，所以极端档位（尤其 B）会有轻微拉伸与衣服褶皱变形，这是「挤压图」的预期风格。

## 玩法

- **主题切换**：右下角「设置 → 主题」可在三套展示之间切换，选择存在 localStorage
- **拖动滑片**（主题一 / 主题二）：鼠标、触屏都可以
- **键盘**：方向键 ±2%，`Shift` + 方向键 ±10%，`PageUp/PageDown` ±10%，`Home/End` 到两端
- **滚轮**：在滑轨上滚动微调（主题一 / 主题二）
- **音效**：滑动时有实时合成的摩擦声，跨档时有咔哒声（首次交互后才会启用，这是浏览器的限制）
- **设置**：右下角「设置」可改主题、标题、副标题、当前主题的档位名称与文案、主题色；配置存在浏览器 localStorage

## 主题三：撞玻璃素材

素材来自 `蓝发鲸鱼女仆 · 图片与 GIF 完整合集`，每个系列同步两张：

- `still.png`：贴玻璃立绘原图（主题三的固定立绘）
- `anim.gif`：同系列 GIF 原件（仅作素材储备，主题三不再播放，原因见下）

主题三固定使用默认系列 `new-burst` 的立绘，其余九组留作素材储备：

> **为什么不用 GIF**：实测十组 GIF 的第 1–9 帧是**同一张立绘按 3×3 切块**（头顶 / 脸 / 胸腰）循环闪现，不是角色动作序列——把 `拆分单帧/` 的 9 个 PNG 按行优先拼回去与原图的平均像素差只有 8.98（全白基线 70.7）。而且 GIF 的帧延时烧在文件里，JS 无法调速、无法 seek，做不到「点击与画面同步」「越点越快」。所以主题三改成用静止立绘做程序化冲击演出：缩放冲击 + 震屏 + 白闪/裂纹 + 碎片 + 连击跳字 + 音效，同一次点击在同一帧内派发，天然对齐。

### 重新同步撞击素材

素材目录默认是 `/Users/yaobinsun/Downloads/jyl-pet/蓝发鲸鱼女仆 · 图片与 GIF 完整合集`，改路径后重跑即可（原图直拷、不重采样）：

```bash
cd whale-girl-changer
python3 tools/sync_impact.py
```

脚本会按 `tools/sync_impact.py` 里的 `SERIES` 表，把每组 `still.png` 与 `anim.gif` 写进 `assets/impact/<id>/`，与 `app.js` 的 `IMPACT_SERIES` 一一对应。

## 重新生成六档图（主题二）

源图在 `assets/source/g-jiya.jpeg`。挤压脚本在 `tools/squeeze_cups.py`，用项目内 Python 环境运行：

```bash
cd whale-girl-changer
../whale-girl-changer/.venv-img/bin/python tools/squeeze_cups.py
```

脚本会在 `assets/` 下重写 `b.jpeg … g.jpeg`（宽 1280、JPEG q88），并把预览图输出到 `tools/preview/`（六档竖排 + B/G 对照）。

可调参数在脚本顶部：

- `CX / R / Y0, Y1`：胸部窗口（横向中心、半宽、纵向范围，按 1792×2400 源图坐标）
- `CUPS`：六档挤压强度 `a_h`，越大压得越小；G 固定为 0（原图）
- `OUT_WIDTH`：输出宽度

脚本内置横向映射单调性断言，参数过大导致采样折叠时会直接报错。

## 安装到 iPhone / Mac（PWA）

是 PWA，安装后独立窗口、离线可用。前提是部署到 HTTPS 地址（GitHub Pages / Cloudflare Pages / Vercel / Netlify 均可），然后：

- **iPhone / iPad（Safari）**：分享 → 添加到主屏幕
- **Mac（Safari）**：文件 → 添加到 Dock
- **Mac（Chrome）**：地址栏安装图标 → 安装

改了资源后，把 `sw.js` 里的 `CACHE_NAME` 改一下（如 `whale-changer-v10`），浏览器会自动清掉旧缓存。

## 实现要点

- **连续变化**：当前素材集的帧叠放，按滑片位置计算三角权重做 opacity 交叉淡入淡出，不是简单跳帧
- **平滑跟手**：目标值 + 每帧插值，点击轨道也会平滑滑过去
- **主题与素材集**：`FRAME_SETS` 里两套滑轨素材自带帧顺序与档位文案；切主题时按 `theme` 选素材集重建帧与刻度，两套文案分别保存在 `gradesBySet`
- **暴击连击**：`hitBurst()` 一次调用内同步派发缩放/震屏/闪白/碎片/跳字/音效，点击与画面同帧，不存在 GIF 与定时器不同步的问题；连击档位与「越点越快」由点击间隔换算的 intensity 决定
- **音效**：Web Audio API 实时合成——摩擦声（带通白噪声）、咔哒声（三角波），不加载任何音频文件
- **无后端**：所有配置存 localStorage，旧版 `theme: cup` 与 `grades` 配置会自动迁移
- **同源同画布**：同一素材集内的帧尺寸与构图一致，切换不跳位
